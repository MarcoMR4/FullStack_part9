# 📘 Part9c – API con Express + TypeScript

Este proyecto es una base sencilla para construir una API usando **Express**, **TypeScript**, **ESLint** y **ts-node-dev** para un entorno de desarrollo eficiente.

---

## 🚀 Requisitos previos

Asegúrate de tener instalado:

- **Node.js** v18+
- **npm** (incluido con Node)

Verifica tus versiones:

```bash
node -v
npm -v
```

* Instalación de proyecto:

```
git clone <URL-del-repositorio>
```

* Entrar a directorio: 

```
cd <ruta_de_proyecto_instalado>
```

* Instalar dependencias: 
```
npm install
```

* Ejecuta el servidor con recarga automática usando ts-node-dev:
```
npm run dev
```

* Analizar código con ESLint: 
```
npm run lint
```

* Compilar código Typescript: 
```
npm run tsc
```

* Ejecutar versión compilada para publicar: 
```
npm run start
```
